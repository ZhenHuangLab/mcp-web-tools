# Changelog

## 2.0.0

First public release of MCP Web Tools.

- Web reader: fetch web pages and online documents as Markdown, with content selection and pagination.
- HTTP tools: send requests, parse JSON APIs, check URLs, and fetch small batches.
- Independent Cloudflare Workers deployments with Streamable HTTP MCP endpoints and HTTP APIs.
- Deploy to your own `workers.dev` subdomain with no custom domain configuration.
- English and Chinese deployment guides, ChatGPT plugin instructions, and an AI agent deployment prompt.
- MIT license.
